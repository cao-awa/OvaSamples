## 这是什么

OvaSamples是一系列为[Ovatoxin](https://github.com/cao-awa/Ovatoxin)框架编写的样例代码，它用于展示Ovatoxin的各种功能和理论上限，Ovatoxin版本总是追随最新版，不会使用任何旧版编写样例。

在Releases中可以下载到能够直接运行的fat jar，通过传入实参``-Dtarget=...``选择不同的样例展示，没有传入``-Dtarget``时默认为``components``。

### ``-Dtarget`` 参数

| 值          | 类型   |
|------------|------|
| components | 组件汇总 |
