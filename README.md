## What is this

OvaSamples is a collection of sample code written for the [Ovatoxin](https://github.com/cao-awa/Ovatoxin) framework. It showcases Ovatoxin's various features and theoretical limits. The Ovatoxin version always tracks the latest release, and no sample is ever written against older versions.

You can download a directly runnable fat jar from Releases. Pass the argument `-Dtarget=...` to choose a different sample; when `-Dtarget` is not provided, it defaults to `components`.

### The `-Dtarget` parameter

| Value      | Type                |
|------------|---------------------|
| components | Component overview  |
